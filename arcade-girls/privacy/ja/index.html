アーケードガールズ（以下「アプリ」）は、端末の中でプレイするミニゲームおよびコレクションアプリです。開発者は会員アカウントを作成せず、ゲームサーバーも運営しません。

1. 収集しないもの

開発者は次のことを行いません。

  • 会員登録、ログイン、ソーシャルアカウント連携
  • アプリ内課金、決済情報の収集
  • 独自の分析（Analytics）SDK、クラッシュレポート SDK の導入
  • 氏名、メールアドレス、連絡先、写真、位置情報、連絡先一覧をアプリが読み取り、サーバーへ送信すること

2. 端末内のみに保存するデータ

進行状況は Android SharedPreferences（アプリ専用のローカルストレージ）にのみ保存されます。開発者のサーバーには送信されません。

  • コイン残高とコイン履歴
  • 図鑑（ギャラリー）の解除状態
  • ミニゲームの最高記録と進行中のボード
  • 言語、サウンド、振動、カラーテーマの設定

アプリを削除するか、システム設定で保存領域を消去すると、このデータも一緒に削除されます。アカウントがないため、開発者に削除を依頼すべきサーバー上のデータはありません。端末の外へ復旧用のコピーを送信しません。

3. 広告と広告識別子（AdMob）

アプリにバナー広告や強制的なインタースティシャル広告はありません。利用者が報酬ボタンをタップしたときにのみ、Google AdMob のリワード広告を再生します。

この過程で、Google Mobile Ads SDK が次の情報を処理する場合があります。

  • 広告 ID（Android 広告 ID、AAID）
  • 広告リクエストに必要な端末情報、IP アドレス、おおよその位置情報（Google が広告配信の過程で処理）

この情報は、広告の提供、不正クリックの防止、広告成果の測定のために Google が処理します。開発者は別の分析ツールで広告 ID を収集しません。Google の処理については、Google プライバシーポリシーをご覧ください。

Android の設定で広告 ID を削除またはリセットでき、広告のカスタマイズをオフにできます。経路は端末によって異なりますが、通常は 設定 → Google → 広告 です。

広告を読み込むにはインターネット接続が必要です。オフラインでもゲームプレイとローカル保存は動作し、広告だけが再生されません。

4. 第三者提供

開発者は利用者のデータを販売しません。広告を再生するときに Google（AdMob）が上記第3項の情報を自らのポリシーに従って処理するほかは、開発者は個人情報を第三者に提供しません。

5. 子ども

このアプリは子どもを対象としていません。満14歳未満の子どもの個人情報を故意に収集しません。コンテンツのレーティングはストアの等級審査に従い、韓国基準では15歳利用可（15세 이용가）を前提としています。

6. 権限

  • インターネット: 利用者が選択したリワード広告を読み込むために使用します。
  • 広範なストレージへのアクセス権限は要求しません。ゲームデータはアプリ専用領域にのみ保存されます。

7. 変更

方針が変更された場合は、このページの施行日を更新し、ストア掲載情報のプライバシーポリシー URL は同じアドレスに維持します。設定画面のアドレスは、アプリ内の PublicLinks.privacyPolicyUrl と一致している必要があります。

8. アプリ-ads.txt

AdMob のインベントリ確認用 app-ads.txt は、開発者サイトのドメインルートに置きます。

  • プライバシーポリシー: https://hodaball37.github.io/arcade-girls/privacy
  • app-ads.txt（同じホストのルート）: https://hodaball37.github.io/app-ads.txt

app-ads.txt の内容は、AdMob コンソールが案内する公開者 ID の1行をドメインルートに置くものです。公開者 ID は App ID を発行した後に記入します。このファイルは GitHub ユーザーページリポジトリ（hodaball37.github.io）のルートに置く必要があり、arcade-girls/ 以下のパスにだけあると AdMob は見つけられません。
