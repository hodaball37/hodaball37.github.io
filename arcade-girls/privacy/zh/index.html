Arcade Girls 个人信息处理方针

如译文与韩文版有出入，以韩文版为准。

生效日期: 2026-11-25

应用名称: 아케이드 걸즈 (Arcade Girls)

Android 包名: com.hodaball.arcadegirls

开发者: hodaball

联系方式: hodaball37@gmail.com

아케이드 걸즈（以下简称“应用”）是在设备上游玩的迷你游戏和收集类应用。开发者不创建会员账户，也不运营游戏服务器。

1. 不收集的信息

开发者不会进行以下行为：

  • 注册、登录或社交账号关联
  • 应用内购买，或收集支付信息
  • 安装自行使用的分析（Analytics）SDK 或崩溃报告 SDK
  • 由应用读取姓名、电子邮箱、联系方式、照片、位置或通讯录并发送到服务器

2. 仅存储在设备上的数据

进度仅保存在 Android SharedPreferences（应用专用的本地存储）中，不会上传到开发者服务器。

  • 金币余额和金币记录
  • 图鉴（图库）解锁状态
  • 迷你游戏最高记录和进行中的游戏盘面
  • 语言、声音、振动和颜色主题设置

卸载应用或在系统设置中清除存储空间时，这些数据也会一并删除。由于没有账户，不存在需要向开发者提出删除请求的服务器数据。我们不会将恢复用副本发送到设备之外。

3. 广告与广告标识符（AdMob）

应用中没有横幅广告，也没有强制插页广告。仅在用户点击奖励按钮时，才会播放 Google AdMob 激励广告。

在此过程中，Google Mobile Ads SDK 可能会处理以下信息：

  • 广告 ID（Android 广告 ID，AAID）
  • 广告请求所需的设备信息、IP 地址和大致位置（由 Google 在投放广告过程中处理）

这些信息由 Google 用于提供广告、防止无效点击以及衡量广告效果。开发者不会通过单独的分析工具收集广告 ID。有关 Google 的处理，请参阅Google 隐私政策。

您可以在 Android 设置中删除或重置广告 ID，也可以关闭广告个性化。路径因设备而异，通常为 设置 → Google → 广告。

加载广告需要互联网连接。离线时游戏游玩和本地存储仍可使用，只是广告不会播放。

4. 向第三方提供

开发者不会出售用户数据。除在播放广告时 Google（AdMob）按其政策处理上述第 3 项所述信息外，开发者不会向第三方提供个人信息。

5. 儿童

本应用不以儿童为对象。我们不会故意收集未满 14 周岁儿童的个人信息。内容分级遵循商店分级审核，并以韩国标准的 15 岁以上可用（15세 이용가）为前提。

6. 权限

  • 互联网：用于加载用户选择观看的激励广告。
  • 不会广泛请求存储访问权限。游戏数据仅保存在应用专用区域。

7. 变更

方针如有变更，我们将更新本页的生效日期，并在商店上架信息中保持相同的个人信息处理方针 URL。设置界面中的地址必须与应用内的 PublicLinks.privacyPolicyUrl 一致。

8. 应用-ads.txt

用于 AdMob 库存验证的 app-ads.txt 放在开发者网站的域名根目录。

  • 个人信息处理方针: https://hodaball37.github.io/arcade-girls/privacy
  • app-ads.txt（同一主机的根目录）: https://hodaball37.github.io/app-ads.txt

app-ads.txt 的内容是 AdMob 控制台提供的一行发布商 ID，放在域名根目录。发布商 ID 将在申请到 App ID 后填写。该文件必须放在 GitHub 用户页面仓库（hodaball37.github.io）的根目录；如果只放在 arcade-girls/ 子路径下，AdMob 将无法找到。
