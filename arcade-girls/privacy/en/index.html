Arcade Girls Privacy Policy

If a translation differs from the Korean version, the Korean version prevails.

Effective date: 2026-11-25

App name: Arcade Girls (아케이드 걸즈)

Android package name: com.hodaball.arcadegirls

Developer: hodaball

Contact: hodaball37@gmail.com

Arcade Girls (the “App”) is a minigame and collection app that is played on the device. The developer does not create user accounts and does not operate a game server.

1. What we do not collect

The developer does not:

  • Provide sign-up, login, or social-account linking
  • Offer in-app purchases or collect payment information
  • Install its own analytics SDK or crash-reporting SDK
  • Have the App read names, email addresses, contact details, photos, location, or contact lists and send them to a server

2. Data stored only on the device

Progress is stored only in Android SharedPreferences (the App’s private local storage). It is not uploaded to a developer server.

  • Coin balance and coin history
  • Collection (gallery) unlock status
  • Minigame high scores and in-progress boards
  • Language, sound, vibration, and color-theme settings

If you uninstall the App or clear its storage in system settings, this data is deleted as well. Because there is no account, there is no server-side data for which you would need to request deletion from the developer. We do not send backup copies off the device.

3. Advertising and advertising identifiers (AdMob)

The App has no banner ads and no forced interstitial ads. A Google AdMob rewarded ad is played only when the user taps the reward button.

In this process, the Google Mobile Ads SDK may process the following:

  • An advertising ID (Android Advertising ID, AAID)
  • Device information needed for ad requests, IP address, and approximate location (processed by Google in the course of serving ads)

This information is processed by Google to serve ads, prevent invalid clicks, and measure ad performance. The developer does not collect advertising IDs with a separate analytics tool. For an explanation of Google’s processing, see the Google Privacy Policy.

You can delete or reset your advertising ID in Android settings, and you can turn off ad personalization. The path varies by device and is usually Settings → Google → Ads.

An internet connection is required to load ads. Gameplay and local storage still work offline; only ads will not play.

4. Disclosure to third parties

The developer does not sell user data. Other than Google (AdMob) processing the information described in section 3 under its own policies when an ad is played, the developer does not provide personal information to third parties.

5. Children

This App is not directed at children. We do not knowingly collect personal information from children under 14. Content ratings follow store rating review, and we assume a 15+ rating (15세 이용가) under Korean standards.

6. Permissions

  • Internet: used to load the rewarded ads the user chooses to watch.
  • We do not request broad storage-access permission. Game data is kept only in the App’s private storage.

7. Changes

If this policy changes, we will update the effective date on this page and keep the same privacy policy URL in the store listing. The address in the settings screen must match PublicLinks.privacyPolicyUrl in the App.

8. app-ads.txt

The app-ads.txt file used for AdMob inventory verification is placed at the root of the developer site domain.

  • Privacy policy: https://hodaball37.github.io/arcade-girls/privacy
  • app-ads.txt (root of the same host): https://hodaball37.github.io/app-ads.txt

The contents of app-ads.txt are a single publisher ID line provided by the AdMob console, placed at the domain root. The publisher ID will be filled in after an App ID is issued. This file must be at the root of the GitHub user-pages repository (hodaball37.github.io); if it is only under the arcade-girls/ path, AdMob will not find it.
