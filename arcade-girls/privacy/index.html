아케이드 걸즈 개인정보처리방침

시행일: 2026-11-25

앱 이름: 아케이드 걸즈 (Arcade Girls)

Android 패키지명: com.hodaball.arcadegirls

개발자: hodaball

문의: hodaball37@gmail.com

아케이드 걸즈(이하 "앱")는 기기 안에서 플레이하는 미니게임과 컬렉션 앱입니다. 개발자는 회원 계정을 만들지 않으며, 게임 서버를 운영하지 않습니다.

1. 수집하지 않는 것

개발자는 다음을 하지 않습니다.

  • 회원가입, 로그인, 소셜 계정 연동
  • 인앱 결제, 결제 정보 수집
  • 자체 분석(Analytics) SDK, 충돌 리포트 SDK 설치
  • 이름, 이메일, 연락처, 사진, 위치, 연락처 목록을 앱이 읽어 서버로 전송

2. 기기에만 저장하는 데이터

진행 상황은 Android SharedPreferences(앱 전용 로컬 저장소)에만 있습니다. 개발자 서버로 올라가지 않습니다.

  • 코인 잔액과 코인 내역
  • 도감(갤러리) 해금 상태
  • 미니게임 최고 기록과 진행 중 보드
  • 언어, 소리, 진동, 색 테마 설정

앱을 지우거나 시스템 설정에서 저장 공간을 지우면 이 데이터도 함께 삭제됩니다. 계정이 없으므로 개발자에게 삭제 요청을 보낼 서버 데이터는 없습니다. 기기 밖으로 복구 사본을 보내지 않습니다.

3. 광고와 광고 식별자 (AdMob)

앱에는 배너 광고와 강제 전면 광고가 없습니다. 이용자가 보상 버튼을 눌렀을 때만 Google AdMob 보상형 광고를 재생합니다.

이 과정에서 Google Mobile Ads SDK가 다음을 처리할 수 있습니다.

  • 광고 ID (Android 광고 ID, AAID)
  • 광고 요청에 필요한 기기 정보, IP 주소, 대략적인 위치(Google이 광고를 내보내는 과정에서 처리)

이 정보는 광고 제공, 부정 클릭 방지, 광고 성과 측정을 위해 Google이 처리합니다. 개발자는 별도의 분석 도구로 광고 ID를 모으지 않습니다. Google의 처리에 대한 설명은 Google 개인정보처리방침을 참고하세요.

Android 설정에서 광고 ID를 삭제하거나 재설정할 수 있고, 광고 맞춤설정을 끌 수 있습니다. 경로는 기기마다 다르며 보통 설정 → Google → 광고 입니다.

광고를 불러오려면 인터넷 연결이 필요합니다. 오프라인에서도 게임 플레이와 로컬 저장은 동작하고, 광고만 재생되지 않습니다.

4. 제3자 제공

개발자가 이용자 데이터를 판매하지 않습니다. 광고를 재생할 때 Google(AdMob)이 위 3항의 정보를 자신의 정책에 따라 처리하는 것 외에는, 개발자가 개인정보를 제3자에게 넘기지 않습니다.

5. 아동

이 앱은 아동을 대상으로 하지 않습니다. 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다. 콘텐츠 수위는 스토어 등급 심사를 따르며, 국내 기준으로 15세 이용가를 전제로 합니다.

6. 권한

  • 인터넷: 이용자가 선택한 보상형 광고를 불러오기 위해 사용합니다.
  • 저장소 접근 권한을 넓게 요청하지 않습니다. 게임 데이터는 앱 전용 영역에만 있습니다.

7. 변경

방침이 바뀌면 이 페이지의 시행일을 고치고, 스토어 등록정보의 개인정보처리방침 URL을 같은 주소로 유지합니다. 설정 화면의 주소는 앱에 들어 있는 PublicLinks.privacyPolicyUrl과 같아야 합니다.

8. 앱-ads.txt

AdMob 인벤토리 확인용 app-ads.txt는 개발자 사이트 도메인 루트에 둡니다.

  • 개인정보처리방침: https://hodaball37.github.io/arcade-girls/privacy
  • app-ads.txt (같은 호스트의 루트): https://hodaball37.github.io/app-ads.txt

app-ads.txt 내용은 AdMob 콘솔이 안내하는 게시자 ID 한 줄을 도메인 루트에 둡니다. 게시자 ID는 App ID를 발급한 뒤 채웁니다. 이 파일은 GitHub 사용자 페이지 저장소(hodaball37.github.io)의 루트에 두어야 하며, arcade-girls/ 하위 경로에만 있으면 AdMob이 찾지 못합니다.
